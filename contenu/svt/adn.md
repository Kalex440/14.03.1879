## Cours

### 1. Où se trouve l'ADN ?

Chez les eucaryotes (animaux, végétaux, champignons), l'ADN est dans le **noyau** de chaque cellule, sous forme de **chromosomes**. L'être humain possède **23 paires** de chromosomes, soit 46.

### 2. La structure de l'ADN

L'ADN (**acide désoxyribonucléique**) est une molécule en **double hélice**, formée de deux brins enroulés. Chaque brin est une suite de **nucléotides**, qui portent l'une des 4 bases :

- **A** (adénine), **T** (thymine), **C** (cytosine), **G** (guanine).

Les bases sont **complémentaires** d'un brin à l'autre : **A** avec **T**, **C** avec **G**.

> 💡 Moyen de retenir : « **A**nimal **T**erritorial, **C**hat **G**ourmand ».

### 3. Gènes et allèles

- Un **gène** est une portion d'ADN qui porte l'information pour un caractère (par exemple le groupe sanguin).
- Un **allèle** est une **version** d'un gène. Les allèles diffèrent par leur séquence de nucléotides (à la suite de mutations).

### 4. Une molécule universelle

Tous les êtres vivants ont de l'ADN construit avec les mêmes 4 bases : c'est un argument en faveur d'une **origine commune** des êtres vivants. C'est aussi ce qui permet la **transgenèse** (un gène d'une espèce peut s'exprimer dans une autre).

## Exercices

### Exercice 1 — Le brin complémentaire

Un brin d'ADN a la séquence : `A T T G C A G`. Écris le brin complémentaire.

Correction :

`T A A C G T C` (A ↔ T et C ↔ G).

### Exercice 2 — Gène ou allèle ?

Le groupe sanguin est déterminé par un gène qui existe en version A, B ou O. Que sont A, B et O ?

Correction :

Ce sont trois **allèles** du même gène : trois versions qui diffèrent par leur séquence de nucléotides.

## QCM

? Chez l'humain, l'ADN se trouve principalement :
+ dans le noyau des cellules
- dans le sang uniquement
- dans la membrane des cellules
> Les chromosomes sont dans le noyau (il y a aussi un peu d'ADN dans les mitochondries).

? La base complémentaire de C (cytosine) est :
- A
- T
+ G
> C s'associe toujours avec G, et A avec T.

? Un allèle est :
- un chromosome entier
+ une version d'un gène
- une cellule sexuelle
> Un même gène peut avoir plusieurs allèles.

? L'universalité de l'ADN permet notamment :
+ la transgenèse
- la photosynthèse
- la digestion
> Un gène transféré dans un autre organisme peut y être lu et exprimé.
